# Resume versions

> [!tip] How to fill this
> One row per version. The PDF lives in `raw/resumes/` and is never edited; a new version is a new file. Name versions by season, role family, and number (`{{season_tag}}-swe-v1`). Every application note records which version was sent, so you can trace a rejection to a resume.

## Rules for every version

- One page.
- Every bullet is supported by a tagged claim in `profile/`.
- Numbers over adjectives. No em-dashes.
- Graduation date and enrollment status match [[profile/education]].
